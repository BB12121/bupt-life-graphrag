# 五分钟演示脚本

## 启动

在项目目录运行 npm start，打开 http://127.0.0.1:4173。默认 demo，顶部明确标注“演示版”；无需后端与模型。

## 1. 首屏与核心关系问题（约 90 秒）

1. 展示简洁导航和问题输入，版本信息在结果与原文中查看。
2. 点击“预约平台还能办理什么？”。
3. 读结论，指出共用平台不代表共用办理地点。
4. 查看三条路径，点击 路径 2/3 切换服务。
5. 指出最后一跳箭头向左，是事实方向，不是画错。
6. 点击引用或关系切换依据，点“查看原文”。
7. 展示固定 commit、41–43 行高亮与原文；第二份依据为常用网站 112–120 行。

## 2. 澄清（约 45 秒）

校区选“暂不指定”，输入“学活是什么？”。

选择沙河或海淀学生活动中心，再点“确认并查询”。说明前端使用 mention→entityId 重发，不自行猜测别名。

也可输入“校园一卡通怎么补办？”：未指定校区时先澄清；选择两校区会得到不同原文。费用和时效提醒会保留。

## 3. 资料与更新（约 60 秒）

进入“指南”，搜索“校园网”，查看阅读与原文行号切换。目录分组只用于导航。

进入知识库，点“检查更新”，观察阻塞 loading 和 changed=false 回执。说明演示不联网同步，真实模式会调用 FastAPI。

## 4. 对比与手机（约 60 秒）

打开检索对比，运行默认问题。hybrid/vector 顺序执行，来源版本一致；前者有图路径，后者只有文本依据。这是人工核对示例，不是效果或性能排名。

用窄屏查看移动导航与“结论/路径/原文”页签；路径竖排，仍可逐跳核查。

## 状态测试用问题

| 输入 | 预期 |
| --- | --- |
| 沙河雁南一站式多功能厅怎么预约？ | answered，两跳 |
| 使用信息服务门户需要校园网环境吗？ | answered，一跳条件关系 |
| 学活是什么？（不指定校区） | needs_clarification，实体选择 |
| 校园一卡通怎么补办？（不指定校区） | needs_clarification，校区选择 |
| 现在雁南多功能厅开放吗？ | abstained/realtime_unavailable |
| 网上服务大厅需要校园网吗？ | abstained/no_evidence，不套用其他平台要求 |
| 多功能厅预约平台部分结果 | partial/search_truncated，明确是状态样例 |
| 多功能厅预约平台交集 | answered，两个查询分支 |
| 冲突状态演示 | partial/conflicting_evidence，空答案，不编造冲突事实 |
| 任意未覆盖问题 | unsupported_query，提示只内置有限示例 |

多功能厅示例对应沙河，若选择海淀会要求确认校区。

## 展示时不要声称

- 已部署本地 Qwen 或执行了真实向量/图检索。
- 有 SSE、全量知识图谱、实时信息或 Web 审核。
- 引用数量代表正确率，演示等待代表模型延迟。

真实模型与目标笔记本评测应在后端接入后进行。
